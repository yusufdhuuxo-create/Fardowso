# Fardowso

## Overview
This is a basic static website project imported from GitHub. The repository was initially empty except for configuration files, so a simple welcome page has been created.

## Project Structure
- `index.html` - Main welcome page
- `README.md` - Project description
- `.gitignore` - Git ignore rules (configured for CodeIgniter PHP framework)

## Setup
The project runs a simple Python HTTP server to serve static HTML files on port 5000.

## Development
- The web server is configured to run automatically on port 5000
- The site is accessible through the Replit webview preview

## Deployment
- Configured as a static site deployment
- The root directory is served as the public directory
